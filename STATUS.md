## Текущий фокус
Фазы 1–4 завершены: базовый скелет, оповещения по расписанию (Gismeteo + Ollama + задача `weather`), хранилище (интерфейс + SQLite), каркас событий (EventSource/EventProcessor с дедупликацией) и деплой (systemd-юнит + crontab). Погода берётся с открытого JSON-эндпоинта Gismeteo (температура по 4 частям суток: ночь/утро/день/вечер, без десятых), оформляется LLM с `think=False` и отправляется как Telegram HTML — компактно, только на русском, заголовок «Погода в Москве», части суток одной строкой; опционально без звука (`weather.silent`). Документация актуальна, код покрыт тестами (~97%, 49 тестов), боевой прогон задачи `weather` выполнен end-to-end с доставкой в Telegram.
