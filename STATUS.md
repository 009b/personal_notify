## Текущий фокус
Фазы 1–4 завершены: базовый скелет, оповещения по расписанию (Gismeteo + Ollama + задача `weather`), хранилище (интерфейс + SQLite), каркас событий (EventSource/EventProcessor с дедупликацией) и деплой (systemd-юнит + crontab). Погодное оповещение оформляется LLM с `think=False` (~20 с вместо ~73 с) и отправляется как Telegram HTML с санитизацией. Документация актуальна, код покрыт тестами (~97%, 50 тестов), боевой прогон задачи `weather` выполнен end-to-end с доставкой в Telegram.
