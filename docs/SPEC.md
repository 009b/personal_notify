# Спецификация: personal_notify

> Статус: ЧЕРНОВИК — заполняется до начала реализации

## 1. Назначение

Персональный Telegram-бот для агрегации уведомлений из разных источников в единый канал.

Бот работает только для одного пользователя (владельца), доступ ограничен по `user_id`.
